# Handyman Apartment — Product Baseline v1.0

## Surface ownership
- **Handyman-Frontend**: Customer Care experience launched from BM Super App.
- **Mob-Handyman**: Lead Worker / field execution.
- **Handyman-Operations**: Dispatcher and Admin operations/configuration/finance/access.
- **Handyman-Backend**: sole lifecycle/business/authorization/financial authority.
- **Asentra-SaaS**: platform package/subscription/entitlement only.

## Customer Care journey
Catalogue → Request → Triage/Inspection visibility → Quotation/Approval → Tracking → Payment → BAST → Warranty.

## Field journey
Assigned Job → Arrival Verification → Check-In → Start → Pause/Resume → Material Run/Material Execution → Complete → Evidence → QC/Rectification → Check-Out.

## Operations journey
Dispatch Queue → Provider/Lead/Crew Assignment → Schedule/Permit → Monitor → Exceptions → QC/Rework Coordination → Warranty/Rework → Reporting.

## Authority
Persona → Surface → Role → Capability → Backend Authorization. UI visibility is never authorization.
